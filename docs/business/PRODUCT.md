# Product

CowWorker helps people manage their job search in one workspace. Marty is the first target user.

## Product direction

The intended workflow connects a saved vacancy, tailored documents, an application, interview preparation, and the next action.
The initial interface language is English. Windows 11 and macOS are required desktop targets; mobile scope remains open.

## Proposed first useful release

- Save a vacancy and its original source.
- Maintain a career profile and prepare resume and cover letter versions.
- Record an application with the exact documents sent.
- Show the next action and its date.

This release boundary is a proposal. AI analysis, document import, and external integrations still need technical validation.

## Current state

The user accepted the stack, storage direction, and first visual prototype with a hideable sidebar.
The first local workflow now includes manual vacancy capture, text document versions, application history, next actions, and profile facts.
Windows native checks verify the workflow and persistence across restarts.
AI, PDF and DOCX import, external integrations, synchronization, and mobile delivery remain open.
