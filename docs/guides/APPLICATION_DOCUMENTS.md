# Prepare a resume and cover letter

1. Open **Universal Add**. Select **Choose files** and choose your old PDF or DOCX resume.
2. Wait for extraction. Select **Review**, check the text, and set **Category** to **Resume**.
3. Select **Save reviewed document**. CowWorker opens the saved document and retains the original file.
4. Open **Universal Add** again. Paste the vacancy text or its public URL, or choose screenshot files.
5. For a URL, enable the displayed fetch permission. A restricted page can require pasted text or screenshots.
6. For several screenshots, select their **Combine** boxes in reading order. Select **Combine sources into one vacancy**.
7. Review the extracted text, role, and company. Set **Save as** to **Vacancy** if classification was uncertain.
8. Select **Save reviewed vacancy**, then **Prepare documents** on its detail panel.
9. Select the original resume version. Select **Create tailored resume** or **Create cover letter**.
10. Select **Edit latest** to write the content. Save the new version, then select **Export .pdf**.

Each prepared document is separate from the original resume. Each content edit creates a new version.
The version selector lets you export an earlier version. Submitted applications retain their exact submitted versions.
PDF export creates a simple text layout with an embedded Unicode font. It does not reproduce the imported document's original design.

## Optional AI assistance

Open **AI → AI settings** and enter a compatible completion endpoint, model, and credential if required.
For a prepared document, the AI panel selects resume tailoring or cover letter generation automatically.
Enter your instruction, select **Preview AI Operation**, and review the destination and exact input data.
The input includes the selected original resume and the related vacancy.
Run the operation, review the proposed content, and select **Apply proposal** if you accept it.
You can edit the new version before exporting it.

The manual workflow and local Windows OCR do not require an AI account.
OCR quality depends on image clarity and installed Windows recognition languages. Always review extracted text.
PDF files with both text and scanned pages can require separate screenshot imports for pages without extracted text.

Open **Settings** in the sidebar to see the application version.
